# Prism Launcher 🌈

**Android in your colors.**

Prism Launcher is an Android launcher focused on deep theming,
flexible folders, icon customization and Material You.

## Included features

- Dynamic Material You / wallpaper theming
- Glass, blur, AMOLED, vibrant and pastel themes
- OPPO-style resizable large folders
- Icons that grow with folder size
- 1x1, 2x1, 2x2, 3x2 and 3x3 folders
- Per-folder icon size and styling
- Android icon-pack support
- Prism Forge for missing icon-pack icons
- Icon-pack mixing
- Advanced grid and spacing controls
- Gestures
- Widget stacks
- Backup and restore
- Adaptive launcher profiles
- Prism app-drawer profiles
- Customizable Prism quick menu

## Development

Active development takes place on `prism-dev`.

### Milestones

1. Prism branding and Android 16 base
2. Prism Theme Engine
3. Resizable large folders
4. Prism Forge
5. Advanced gestures and widgets

## Upstream

Prism Launcher currently uses Lawnchair as its launcher foundation.
Lawnchair is based on Android's open-source Launcher3.

Applicable upstream licenses and notices remain included.
